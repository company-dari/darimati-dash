  • 즉시 동기화 주소를 열었는데 화면이 깨져 보여도, 스크립트는 실제로 실행된 것입니다. 실패로 보고 계속 다시 누르면 같은 작업이 여러 번 돕니다. 결과는 시트에서 확인하세요.
  • 교환 회수 운송장으로 발주시트 행을 만들지 말 것. 나가는 걸로 읽어서 재고가 한 번 더 빠집니다.
  • 향동 재고가 없어 N배송에서 빼주는 경우는 자동에서 제외됩니다 — 입출고기록에 직접 넣어야 합니다.
  • 창고 이름은 “향동” / “N배송”으로 정확히. 오타 나면 매칭이 안 돼 숫자가 안 움직입니다.
