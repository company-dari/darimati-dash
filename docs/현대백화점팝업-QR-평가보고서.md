# 현대백화점 팝업 폼보드 QR — 구축·평가 보고서

- 작성일: 2026-08-25
- 대상: 현대백화점 팝업 현장 폼보드에 인쇄할 QR
- 코드: `hyundai-popup` / 이름: `현대 백화점 팝업`
- 상태: **등록·배포·라이브 착지 검증 완료**

---

## 1. 무엇이 문제였나

팝업 일정은 정해졌는데 **랜딩페이지가 아직 없다.** 신청 페이지는 쇼피파이에
따로 만들어 붙일 계획이라 주소가 확정되지 않았다.

여기서 흔히 나는 사고가 이것이다.

> 인쇄를 미룬다 → 인쇄소 일정에 쫓긴다
> 또는 급하게 아무 주소나 박아 인쇄한다 → **주소가 바뀌는 순간 폼보드가 전부 쓰레기가 된다.**

인쇄물은 한 번 나가면 되돌릴 수 없다. 그래서 "나중에 바꿀 수 있다"가 아니라
**"바꿀 수 있게 만들어 놓고 인쇄한다"** 가 전제여야 한다.

## 2. 어떻게 풀었나

QR에 **목적지를 넣지 않는다.** 우리 고정 주소만 넣는다.

```
[폼보드 QR]
   │  https://company-dari.github.io/darimati-dash/q/?code=hyundai-popup   ← 영원히 안 바뀜
   ▼
[링크표(구글시트)]  ← 여기 한 줄만 갈아끼운다
   ▼
[지금의 목적지]  현재: https://www.darimati.us/pages/join (임시)
                 확정 후: 팝업 신청 페이지
```

바뀌는 것은 시트의 한 줄뿐이고, **인쇄물은 손대지 않는다.**
이 구조는 2026-07-29에 만들어 F45 지점 POP 등으로 이미 검증된 것을 그대로 재사용했다.

## 3. 검증 결과 (2026-08-25 실측)

말로 "됐다"가 아니라 실제로 찍어서 확인한 값이다.

| 확인한 것 | 방법 | 결과 |
|---|---|---|
| 링크표 등록 | 목록 조회 | ● `hyundai-popup` 등록됨 (전체 17개) |
| 목적지 응답 | 리다이렉트 API 직접 호출 | `ok:true` → `/pages/join`, 이름 `현대 백화점 팝업` |
| 비상 스냅샷 | `snapshot.py` 재생성 후 배포 | `q/links.js` 에 코드 포함 확인 |
| 배포 반영 | 라이브 파일 재조회 | 3회차 시도에서 반영 확인 (약 40초 소요) |
| **실제 착지** | **브라우저로 QR 주소 열기** | **`회원가입 – darimati` 페이지 도착** |
| 임시 목적지 측정 | 페이지 소스 픽셀 확인 | `fbq` 2회 — 픽셀 살아 있음 |

마지막 두 줄이 핵심이다. API 응답만 보고 끝냈다가 실제로는 죽어 있던 사고가
2026-08-03에 있었기 때문에, **반드시 브라우저로 착지까지** 본다.

## 4. 평가

### 잘 된 점
- **인쇄를 먼저 진행해도 되는 상태를 만들었다.** 랜딩 확정을 기다릴 필요가 없다
- 기존 구조를 그대로 재사용해 새로 만든 것이 없다 → 새 버그가 들어올 자리가 없다
- 임시 목적지를 살아있는 페이지(회원가입)로 걸어, 만약 인쇄물이 먼저 돌아도
  **빈 화면이 아니라 우리 페이지에 떨어진다.** 픽셀도 붙어 있어 모수는 쌓인다
- 등록 직후 스냅샷을 굽고 배포까지 마쳐, 첫 방문자가 죽는 경로를 닫았다

### 남은 위험
- **임시 목적지는 "회원가입"이라 팝업 방문객 의도와 다르다.** 팝업 전에 반드시 교체해야 한다
- 팝업 신청 페이지는 아직 없다. 만들 때 픽셀 + 신청 이벤트를 처음부터 넣어야 한다
  (나중에 붙이면 그 전 방문자는 영영 모수에서 빠진다)
- 팝업 종료 후 `잠시 중지`를 누르지 않으면, 철거된 폼보드 사진 등으로 계속 유입될 수 있다

## 5. 목적지를 바꾸는 방법 (담당자용)

1. https://company-dari.github.io/darimati-dash/qr/ 접속
2. 목록에서 **`현대 백화점 팝업`** 클릭
3. `목적지 — 지금 이 QR이 보내는 곳` 칸에 새 주소 입력
4. **`목적지 저장`** → *"바꿨습니다 — 인쇄된 QR은 그대로 씁니다"* 확인
5. ⚠️ 담당자(개발)에게 알려 **스냅샷 재배포**를 받는다
   (`python3 qr/snapshot.py` + push — 안 하면 첫 방문자가 안내화면을 볼 수 있다)
6. 반드시 **새 탭에서 QR 주소를 직접 열어 착지 확인**

## 6. 인쇄 전 체크

- 인쇄소에는 **SVG**(벡터)로 전달. 파일 뽑기: `node ~/darimati-dash/qr/export.js`
  → 바탕화면 `다리마티-QR/` 에 `현대백화점팝업_darimati-qr-hyundai-popup.svg`
- **최소 2cm 이상**, 흰 여백을 자르지 말 것, 검정/흰배경 유지
- 폼보드는 멀리서 찍는 경우가 많다 → 실제 인쇄 크기로 뽑아 **현장 거리에서 스캔 테스트** 권장

## 7. 다음 할 일

2. 완성 후 목적지 교체 + 스냅샷 재배포 + 착지 재검증
